# Wedding Website

A clean, elegant, and fully responsive wedding website designed to celebrate a special union with simplicity and warmth.

This project focuses on visual storytelling, smooth layout flow, and mobile-first refinement — without unnecessary complexity.

---

## ✨ Features

- Elegant hero section
- Custom-designed photo gallery
- Our Story & Families sections
- Countdown & event details
- Thank You closing section
- Fully responsive (mobile & desktop)
- Lightweight, fast-loading, and accessible

---

## 🛠️ Built With

- HTML5
- CSS3 (Grid & Flexbox)
- Vanilla JavaScript (for interactions, if any)

No external frameworks or heavy libraries are used.

---

## 📱 Responsive Design

The website is carefully optimized for:
- Mobile phones
- Tablets
- Desktop screens

Special attention was given to spacing, layout flow, and image handling on smaller screens.

---

## 📸 Gallery

The gallery uses a custom grid layout on desktop and a clean stacked layout on mobile to ensure visual balance across devices.

---

## 🚀 Usage

You can:
- Host this website on any static hosting service (Vercel, Netlify, GitHub Pages, etc.)
- Customize content, colors, and sections as needed
- Reuse the structure for similar wedding or event websites
